# SQL Server Schemas

Contains DDL scripts for Microsoft SQL Server.

## Conventions
- Use `GO` as a batch separator between statements
- Schema prefix all objects (e.g. `dbo.TableName`)
- Use `NVARCHAR` for all string types to support Unicode

## Folders

| Folder | Description |
|---|---|
| `tables/` | CREATE TABLE statements |
| `views/` | CREATE VIEW statements |
| `stored-procedures/` | CREATE PROCEDURE statements |
